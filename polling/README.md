# polling · 手写轮询实现（1.x，2015）

lazysizes 起步的年代没有 IntersectionObserver，「元素进没进视口」浏览器不会告诉你，只能自己反复问。本案例读这套经典轮询实现的三步定型：整套机制、SVG 兼容、模块化拆分。

## 版本链

| 版本 | 上游 tag | 一步概念 |
|---|---|---|
| 1 轮询核心定形 | 1.3.1 | 事件轮询 + 节流 + expand 预载环 + 类状态机，整套机制一次看全 |
| 2 SVG 支持与调度微调 | 1.4.0 | className 换 getAttribute/setAttribute 兼容 SVG 元素；hFac 横向系数 |
| 3 UMD 拆分与后台标签页 | 1.5.0 | AMD 注册拆出 lazysizes-umd.js；注释里躺着下一代调度的完整草稿 |

## 怎么学

沿版本链走：每版先读版本文档，再开差异面板对照上一版。主文件 `lazysizes.js`（约 700 行）的逐段精读在第 3 版的文件解读里（按 1.5.0 行号写，前两版行号有 ±20 行漂移）。文件树与差异面板已裁掉构建产物与测试（案例目录 `.eduignore`），运行仍是全量代码。
