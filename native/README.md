# native · 平台收编（5.x，2018-19）

浏览器把懒加载做进平台（原生 `loading="lazy"`），库的剩余价值是让位与兜底。本案例读让位协议、兼容长尾、类型收官三步，走完「手写实现 → 库繁荣 → 平台原生 → 库退役」弧线的最后一段。

## 版本链

| 版本 | 上游 tag | 一步概念 |
|---|---|---|
| 1 原生 loading 插件 | 5.0.0 | 库以 native-loading 插件让位——拆自己的监听网、交出加载权（精读在其文件解读） |
| 2 SSR 与 bfcache 修补 | 5.2.2 | SSR 安全传 window、Safari 后退缓存修 visibility、AMD 补全——兼容长尾 |
| 3 末版：类型注解收官 | 5.3.1 | JSDoc 类型补齐、ls-is-cached 缓存标记；维护期的活儿变成写文档，项目定格 |

## 怎么学

沿版本链走，每版先读版本文档再开差异面板。这三年上游每步差异原有 40–60+ 文件，大头是 min 产物重压缩与插件同模式铺开——文件树与差异面板已按案例目录 `.eduignore` 裁掉，只留概念载体（运行仍是全量代码）；第 3 版新增的 `lazysizes.d.ts` 与 `types/` 是概念文件，保留。
