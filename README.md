# lazysizes · 读一个真实前端项目的演进

案例集 = 上游真实项目 [aFarkas/lazysizes](https://github.com/aFarkas/lazysizes)（MIT 许可，图片/iframe 懒加载库）按教学选版的镜像：每个版本挂一个上游 tag（`from:` 坐标，构建期物化原样代码），教学侧只提供解读（doc.md 与文件级解读），不改上游一个字节。

## 案例组织：按上游发布线分系列

| 系列 | 上游区间 | 主线 |
|---|---|---|
| v1-polling | 1.x | scroll/resize 事件轮询 + 节流：懒加载的经典实现形态 |
| v4-observer | 4.x | IntersectionObserver 取代事件轮询：技术被浏览器原生能力取代的演进样本 |

系列之间不连线（各系列独立成链）；上游从 1.x 到 4.x 的中间演进，待核实概念增量后补进对应系列。

## 怎么学

1. 进版本 → 右侧文档面板读该版解读，重点用文件级解读精读 `lazysizes.js` 主文件；
2. 切差异面板对照上一版，聚焦解读点到的文件（真实项目相邻版本间变动文件多，跟随解读而不是通览）；
3. 代码可在线编辑试跑（编辑只保存在本机浏览器，上游代码树只读——受约束是特性）。
