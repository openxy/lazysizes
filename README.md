# lazysizes · 读一个真实前端项目的演进

案例集 = 上游真实项目 [aFarkas/lazysizes](https://github.com/aFarkas/lazysizes)（MIT 许可，图片/iframe 懒加载库）按教学选版的镜像：每个版本挂一个上游 tag（`from:` 坐标，构建期物化原样代码），教学侧只提供解读（doc.md 与文件级解读），不改上游一个字节。

## 案例组织：按上游发布线分系列

| 系列 | 上游区间 | 主线 |
|---|---|---|
| v1-polling | 1.x（2015） | scroll/resize 事件轮询 + 节流 + 全量扫描：懒加载的经典手写实现 |
| v4-mature | 4.x（2017） | 成熟期：requestIdleCallback/rAF 批处理/防抖全部转正；IntersectionObserver 版只留在 src/ 实验位，从未转正 |
| v5-native | 5.x（2018-19，末版 5.3.1） | 平台收编：原生 `loading="lazy"` 把懒加载做进浏览器，native-loading 插件就是库的让位协议，项目收官 |

系列之间不连线（各系列独立成链，按精读学，不按 diff 学）。整个案例集讲一条完整的技术普及弧线：**手写实现 → 库繁荣 → 平台原生 → 库退役**。注意一个反直觉的事实：IntersectionObserver 上市时这个库做过完整重写（`src/lazysizes-intersection.js`，v4 起可在版本树里读到），但主产物始终没换——兼容包袱与用户面怎么影响技术决策，是本案例集最值得学的判断题。

## 怎么学

1. 进版本 → 右侧文档面板读该版解读，重点按 doc/ 文件级解读精读 `lazysizes.js` 主文件（三个系列读同一个文件的三代形态）；
2. 系列间不连线，对照读靠解读里的行号指引（v1 的注释实验代码 → v4 的转正正文，是本案例集独有的「代码考古」线）；
3. 代码可在线编辑试跑（编辑只保存在本机浏览器，上游代码树只读——受约束是特性）；
4. 演示页 `index.html` 的示例图是 2015 年代外链，部分已失效——看加载机制（Network 面板、类切换）不看图。
