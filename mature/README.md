# mature · 调度成熟与生态（2.x–4.x，2016-17）

机制定形后的繁荣期：调度升级（rIC 转正）、争议行为开关化（loadHidden）、生态成型（二十余插件 CommonJS 化），外加一次完整的 IntersectionObserver 重写——但它从未转正，一直躺在 src/ 实验位（这段判断题见 refined 版）。

## 怎么学

沿版本链走，每版先读版本文档再开差异面板。第 1 版的 445 行 diff 是全案例集最大的一步——正是「注释草稿变正文」的现场。文件树与差异面板已裁掉插件目录与构建产物（案例目录 `.eduignore`，插件头部改造是同一模式机械铺开，样本看 polling 的 unveilhooks 与 native 的 native-loading）。
